# 英語やり直しトレーニング v2

松戸高校芸術科合格プロジェクト用のGitHub Pagesサイトです。

## 学習順
1. 1問ずつ練習
2. 10問ミニテスト
3. 総合テスト

最初の「1問ずつ練習」は、2026年度中2 総進テスト第2回7月号の大問5で確認された
`were / Did / doesn't / studied / mine` を中心に作成しています。

各テーマは類題を繰り返し、3問連続正解でクリアです。進捗はブラウザに保存されます。

## GitHub
新規リポジトリのルートへ、このZIPの中身をすべてアップロードしてください。
Settings → Pages → Deploy from a branch → main / (root) で公開できます。

今後、新しい英語テストを追加するときは、問題PDFと解答・解説PDFをもとに、
同じ「1問ずつ → ミニテスト → 総合」の形式で追加できます。
